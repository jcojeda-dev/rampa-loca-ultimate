# Roadmap del Proyecto

## Fase 0: base técnica

- consolidar la arquitectura modular,
- completar documentación,
- estandarizar naming y organización,
- asegurar estabilidad del arranque de cliente y servidor.

## Fase 1: servicios core

- completar servicios de datos, perfiles, economía y notificaciones,
- definir contratos de remotes,
- estabilizar el flujo de carga de módulos.

## Fase 2: experiencia de usuario

- ampliar la capa de controladores,
- preparar la base para interacción, cámara y UI,
- definir el pipeline de eventos del cliente.

## Fase 3: producción

- revisar rendimiento,
- fortalecer seguridad,
- establecer métricas de calidad,
- preparar el proyecto para pruebas y iteración.

## Fase 4: escalado

- introducir nuevas características de forma incremental,
- mantener la separación de capas y la calidad del código,
- evitar la acumulación de deuda técnica.
